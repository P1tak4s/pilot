# Handoff

One click hands the work over to a fresh chat: a handoff is written, the chat is cleared, and the handoff is sent into it as
the first message.

## Flow
1. The person presses `⇥` in the footer (or runs `/effortless handoff`).
2. The mod sends the built-in handoff prompt, or runs the person's own skill (setting `handoffSkill`).
3. When that turn ends (`turn.complete`, main loop), its answer is the handoff.
4. From the session's timer (hooks a turn waits on may not run commands) the mod runs `/clear` through `$.command.run`
   and sends the handoff with `$.prompt.submit`.
5. Setting `handoffAfter`: `continue` (default) carries on with the next step; `confirm` says where things stand and waits.

## Placement
- Footer: `⇥`, always there, one symbol so it takes little room.
- Command: `/effortless handoff`.
- Later (step 2): Handoff in the cold band, and a smart suggestion band when the chat is long (context over about 40%)
  and the judge sees a new task start. At most once per chat; dismissing keeps it quiet until the context grows.

## Not possible
Opening a new chat or archiving the old one: the mod API has no access to the app's chat list.
