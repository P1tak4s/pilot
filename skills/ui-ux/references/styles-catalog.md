# Visual styles catalog

Starting points for the SYSTEM line of the direction contract. Pick one only when it fits the
subject and audience; then adapt fonts and palette to the brand. Rules in the other reference
files (contrast, states, motion, anti-slop) still apply on top of any style.

Data adapted from [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills)
(MIT, Copyright (c) 2026 Bergside). Some entries are named after products or brands; treat them as
inspiration for the look, never copy logos, names or trade dress.

How to read it: "Feel" and "Fonts" are the useful part. Colors marked (placeholder) are the
source template default (the blue/violet pair this skill bans as a reflex), so derive that
palette from the brand instead. Radius is not listed because the source uses 4/8px for every
style; pick it from the feel (sharp for brutalist/editorial/retro, soft for friendly/clay, pill for playful).
