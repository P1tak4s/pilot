# Anti-slop: what makes UI look machine-made

Generated interfaces converge on the same defaults. Each item below is fine when the brief
deliberately asks for it; it is a problem when it shows up because nobody decided otherwise.

## Visual tells

- Purple/indigo-to-blue gradients, aurora/mesh blobs, glowing orbs behind the hero.
- Gradient text on headings; neon outer glows; glassmorphism on every card.
- Centered hero over a dark gradient with a pill badge ("New: v2.0 is here") above the headline.
- The same three cards (icon in a rounded square, bold title, two lines of gray text) as the main feature section.
- Big-number "hero metrics" row (10k+ users, 99.9% uptime, 24/7 support) with no source.
- Cards inside cards; everything in a soft-shadowed rounded rectangle.
- Thick colored left border on callouts, alerts and list items.
- Hard offset "neo-brutalist" shadows (4px 4px 0 black) on an otherwise soft design.
- Sparklines, progress rings and fake charts as decoration instead of real data.
- Monospace everywhere to look "technical" without any code or data.
- Emoji or Unicode glyphs as icons; mixed icon families; generic user-silhouette avatars.
- Fake product screenshots built from divs (fake terminals, fake task lists, fake dashboards).
- Default browser leftovers next to a custom design (blue selection, default scrollbars, default focus ring, unstyled date picker).
- Three recurring "designed" looks used as reflexes:
  1. warm cream background + high-contrast serif + terracotta/brass accent;
  2. near-black + one acid neon accent + glowing borders;
  3. newspaper hairlines + italic display serif + tiny tracked mono labels.
- Inter or a system sans as the display face of a brand landing; or the current overused "designer" faces (Fraunces, Playfair Display, Instrument Serif, Space Grotesk, Syne) picked by habit.
- Light/dark chosen by category ("dev tool = dark") instead of the user's scene.

## Layout tells

- Eyebrow label above every heading ("FEATURES", "HOW IT WORKS"). Allow at most one eyebrow per three sections.
- Section numbers "01 / 02 / 03" when the content is not a real sequence.
- "Big headline left, small paragraph right" as the header of every section.
- Six identical image-left/text-right rows in a row.
- Bento grids with empty cells or six plain white text cells.
- Logo wall with industry labels under each logo, or plain-text "logos".
- Trust strip, pricing teaser and bullet list crammed into the hero.
- Hero that does not fit the first viewport or a 4-line headline.
- "Scroll to explore" cues, rotated vertical text, decorative crosshairs and grid lines as filler.
- Two marquees on one page; marquee as filler.

## Copy tells

- Filler verbs: Elevate, Seamless, Unleash, Empower, Supercharge, Revolutionize, Next-gen, Game-changer, Delve, Unlock the power of.
- Generic names: John Doe, Jane Smith, Acme Corp, Nexus, Cloudly, SmartFlow.
- Fake-precise metrics (99.97%, 4.1x faster, 2,847 teams) without a real source.
- Lorem ipsum, "Your text here", headings that describe the section instead of saying something ("Our Features").
- Three adjectives in a row ("fast, secure and reliable"); headlines that could fit any product.
- Mixed registers (marketing hype next to technical jargon next to poetry).
- Em dashes everywhere; over-used middle dots as separators.
- "Get started", "Learn more", "Sign up", "Try it free" all on the same page for the same action.

## Motion tells

- Every section fades up identically on scroll.
- Infinite pulses, breathing glows and floating blobs with no meaning.
- Bouncy springs on menus and modals.
- Custom cursors and magnetic buttons on a normal product site.

## What to do instead

- Derive palette, type and one signature element from the subject's own world (see `direction.md`).
- Structure from content: if there are 2 features, show 2; if one is the hero feature, make it big.
- Real assets: screenshots, photos, product UI, custom illustration in one style. When an asset is missing, ask for it or leave a clearly marked placeholder rather than covering it with gradients.
- Copy that only this product could say: specific nouns, real numbers, concrete outcomes.
- One focal motion moment, purposeful micro-interactions, nothing else.
- Specificity test: could a competitor use this page unchanged with their logo? If yes, it is not done.
